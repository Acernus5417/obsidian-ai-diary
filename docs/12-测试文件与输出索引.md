# 0.2.1 测试文件与输出索引

2026-10-13。本轮未新增性能或单元测试。`test-results/` 是本地输出目录，不在插件 ZIP 内，也不包含密钥或真实日记。旧版 `redesign-*` 报告属于 0.2.0。

交付另附 `dist/ai-diary-0.2.1-test-records.zip`，包含当前源码、测试文件、虚构素材、实际输出、评分与截图；不包含 node_modules、仓库配置、真实笔记或凭据。校验值单列在 `dist/TEST_RECORDS_SHA256.txt`，插件安装包仍保持六文件白名单。
