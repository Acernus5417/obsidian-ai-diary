# 自然回顾与 Obsidian 主题适配

2026-10-13，本轮按最新要求替代 0.2.0 的规则式问答设计。

## 对话

采用简短框架、一个日常示例和原始对话，模型直接输出自然中文。默认从今天早上主要做了什么开始，顺着事件问感受、想法和细节，再自然走到中午、下午和晚上。时间顺序是线索，由模型根据已聊内容和作息调整，不编写时段状态机。

语气平实、体贴，像普通聊天；既不抒情拔高，也不刻意用俚语。不要求每轮总结、深挖或提问。用户随时生成，继续、换问法、换方向和跳过仍可使用。

移除情绪词匹配、预设动机黑名单、角度候选、同维度禁止追问、强制分类和问号数量校验。片段索引仅供定位原文，既不指挥提问，也不作为日记额外事实。保留授权、明确跳过、来源隔离、错误处理与保存保护。

## 界面

使用 Obsidian 的背景、文字、边框、强调色、字体、按钮圆角与阅读宽度变量。去掉固定奶油绿配色、品牌装饰和横向大标题。顶部只保留日期与必要操作；对话与预览以正常正文字号呈现。手机继续使用同一独立标签页和底部输入区。

## 本轮验证

不新增性能或单元测试。维护已有集成与界面检查中因行为改变而失效的期望，进行类型与构建检查、浏览器实操和真实 API 交互。

准备工作日、平淡休息日、夜班三份虚构日程。模拟用户掌握隐藏剧本，只回答实际被问到的内容；插件使用真实模型提问、整理和生成，并在隔离内存仓库归档。阅读逐轮问答，按具体事件与情感还原、回答负担、日常语气、忠实性和自主性评分，记录问题、调整提示词、复测。

真实 API 使用已配置模型；用户另行明确授权读取并在内存中解密插件凭据。只发送虚构材料，不读取真实日记，不输出或保存密钥。模型扮演用户有偏差，Agent 的评分也不等同于本人试用或独立人工评审。
