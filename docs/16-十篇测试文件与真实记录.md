# 0.4.0：测试文件与真实记录

仅同一10篇虚构写作样本，包含两种文风、追加与编辑；另8个提问前文回放，不是全量月级或真人试用。主目录 [coherence/README.md](../test-results/coherence/README.md)，效果与不足见 [REVIEW.md](../test-results/coherence/REVIEW.md)。

| 所用文件 | 用途 |
| --- | --- |
| [coherence.ts](../tests/fixtures/coherence.ts) | 10篇问答、8个提问上下文及复核关注点，全部虚构 |
| [coherence-eval.ts](../scripts/coherence-eval.ts) | 实际网关、事实整理/写作/观察/归档、旧新对照、版本保留、请求/响应与失败；来源是当前获授权配置 |
| [verify-coherence.ts](../scripts/verify-coherence.ts) | 从实际解析响应核对10份日记、事实文档/问答/来源、8个提问、编辑与追加、正式文件，并导出Markdown；不自动评分语义 |
| [prompts/index.ts](../src/prompts/index.ts) | 提问、事实整理、全文写作及独立观察的简短框架 |
| [context.ts](../src/ai/context.ts) / [facts.ts](../src/ai/facts.ts) | 有效问答/正文依据与事实文档协议，保护授权及编辑，不评判情绪含义 |
| [diary.ts](../src/application/diary.ts) | 整理→撰写→预览/观察→归档的应用流程 |
| [browser-check.mjs](../scripts/browser-check.mjs) | 已有Chromium流程及本次实际文本重放 |

实际输出：

- writing/*.md、*.json：每篇原问答、旧正文、事实文档、篇章建议、新正文、源映射、实际输入和归档文本。成功主稿4.0.2。
- questions/*.md、*.json：相同前文的旧新实际回应，4.0.1的提问提示与当前相同。
- variants/4.0.0、4.0.1、4.0.2：改前稿；variants/4.0.3为上游429中断稿，不计成功。
- requests.jsonl：137条可核对HTTP，132条2xx、1条网络超时、4条429；保留实际消息、响应及阶段/版本，不保存请求头和凭据。
- fixtures.json、prompts-*.json、baseline-prompts-3.0.5.json：原始样本与提示词。
- vaults、questions-vault：隔离磁盘仓库的问答、事件和实际归档，与真实用户仓库分开。
- integrity.json：实际产物、来源和计数；REVIEW.md：Agent主观分数、具体原句与剩余问题。
- [coherent-flows.json](../test-results/coherent-flows.json)：89项集成/界面流程；coherent-*.png：主题/手机截图；coherent-checks.txt：实际工具摘要。
- [coherent-package-check.json](../test-results/coherent-package-check.json)：安装包CRC、版本、字节和旧包保留。

安装包dist/ai-diary-0.4.0.zip；本轮全部源码/记录包dist/ai-diary-0.4.0-test-records.zip。旧62天输出留在0.3.0记录包，本轮不把它当新版本全量验证。
