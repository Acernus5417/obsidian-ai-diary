# 0.3.0 两个月测试文件与输出索引

本轮不新增或运行性能、单元测试。主要采用真实 API、磁盘事件接续、同素材观察对照、逐日/周期审阅和实际浏览器流程。全部生活素材虚构，未读取真实日记；密钥不在测试文件、日志或记录包中。

## 实际记录

主目录：[test-results/two-months](../test-results/two-months/README.md)。进度文件只反映已完成阶段，未完成或失败不计完成。

- fiction.json：完整生活原稿和审阅视角。
- days/日期.json 与 .md：实际问答、生成日记、观察、来源映射、历史输入、错误、提示词版本、辅助评分和模拟用户偏离。
- vault/日记：正式测试日记；vault/原始问答：原始问答及实际事件接续数据。
- vault/周记 与 vault/月记：独立周期笔记，注明记录覆盖和历史出处。
- requests.jsonl：真实请求状态、输入/输出或摘要、失败和重试；不保存 Authorization 或密钥。
- prompts-版本.json：各实际版本的生产、模拟用户和审阅提示词。
- variants：第一周前后版本及周期原稿，修改不覆盖旧证据。
- period-audits：周月回顾原文、事实输入和辅助审阅。
- scores.csv：辅助模型的原始主观分数，不能直接当质量通过率。
- AGENT-REVIEW-pilot.md：第一周 Agent 实际阅读、问题、修改依据。
- AGENT-REVIEW-early.md、AGENT-REVIEW-july-late.md、AGENT-REVIEW-aug-early.md、AGENT-REVIEW-aug-late.md：按日期分工阅读原问答、正文、新观察和周期笔记，分别记录依据与局限。
- summary.json、integrity.json：实际计数、失败汇总和结构/出处检查；语义质量另见 Agent 复核。
- formatted-output-check.json：62份观察与实际解析响应匹配；5天只归一化重复标题，正文未改，改前JSON保留。
- [two-months-targeted/README.md](../test-results/two-months-targeted/README.md)：14天3.0.4对照、3次写作/对话、4份周月稿；negation-3-0-5为最终四例检查，完整输入输出、提示词、26条请求和Agent意见均在目录中。
