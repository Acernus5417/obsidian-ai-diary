## 根据真实结果修改

观察从“主段加多个模式”收敛为自由的一篇理解与出处；只用获准日记原文，删除此前AI假说的上下文，避免猜想积累。保留情境、反例、未知和可反驳性，不加情绪词表、心理类型、固定问句数量或自动语义评分门槛。

对话遇到已出现的矛盾或新发现先多聊，不因问过一次感受就赶下个时段；聊天不宣称已保存。晚回答的感受放回所属事件。模型返回无效引用/格式时可修复一次，程序不重写情绪含义。重复标题由呈现层归一化，改前JSON保留。

新增周月回顾：周期末确认日记后生成，启动只补已结束周期；授权/来源变化拒绝保存，已有笔记不覆盖，本地新建竞争留备选。日记归档先完成，周期失败独立重试；关闭应用阻止后续调用，已启动归档事务继续补齐。旧配置默认不打开自动回顾。

## 还原效果与剩余问题

完整意见在 test-results/two-months/AGENT-REVIEW.md；定向对照在 two-months-targeted/AGENT-REVIEW.md。Agent主观判断：全量正文忠实4/5，情绪还原3.5/5，观察解释力3.5/5，历史联系3/5，省力程度2.5/5，周月综合3.5/5；不是统计量或心理真实性证明。

有用认识包括：询问标准与当场表达需要的区别；自愿且有范围的帮助与被挤占不同；陪伴不必交出成果；真实急事、疲惫与关系场景会改变反应。定向输出修正了纸上记录、三次相同经历、未出门、错月等具体错误；8/5感受归位，8/30继续聊新发现，8/26不宣称已归档。

改进并不稳定。仍有未记录被写成不存在、纠正助手被读成自我辩护、否定被当相反证据、场景差异被抹平、普通日过度分析。3.0.5四例撤掉一处明确反向引用，但未知答复仍偶有被说成未定。周期文本有综合价值，也仍偏长、建议过多；一篇定向月记把回家没记住聊天误说成实际没被问。模型原文保留，没有人工改成成功样本。

模拟用户会补出剧本没有的细节、迎合问题或说“材料里没写”，另列simulationIssues；正文沿用实际回答不自动算作者编造。固定8答偏向事件补问，有些内心变化未问出，最后问题可能未答；脚本显式继续也可能发生在晚安后。一次虚构人物测试不能推断真人长期体验或潜意识已被识别。
