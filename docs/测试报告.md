# 0.4.0 研究、十篇对照与交付报告

本轮按用户要求仅测试同一10篇样本，另有8个提问前文回放。未新增或运行单元/性能测试。源码候选已完成工程检查，语言效果仍有不足，最后写作提示候选未成功实测。

## 改动

生成改为“有效问答→事实文档与简短篇章建议→结合原问答全文撰写”。事实包括用户表达的感受与想法；问题解释短回答，事实稿可被原文纠正。模型按完整经历组织文章，正文来源为全文范围，细项出处留在事实文档，旧sourceMap仍兼容。事实文档保存在草稿/接续事件中，手动编辑后不复用旧派生稿。

对话从整段判断重心，考虑提问能带来什么新内容、回答是否费力，普通片段可以带过，也可以只回应。时间只是回忆入口。未加情绪词表、心理分类器、硬轮数或自动语义评分门禁。保留授权、出处、编辑与保存保护。

已整理后，以当前正文和新增对话为背景；旧AI问题携带正文及回答依据，编辑/已消费回答/历史撤权或改写后不让旧问题复活删除内容。生成通常增加一次素材整理API请求，不增加用户确认步骤。

## 研究依据

阅读对话指代摘要、Plan-and-Write、细粒度对话事实错误及以未来交互评估澄清问题的论文，查看Reflective Conversational Journal和Virgil实际提示文件。借鉴语境归属、分阶段组织、问题实质与倾听节奏，不移植训练模型、奖励分类器或固定心理路径。论文不是日记效果证明；来源、链接与取舍见 docs/15-连贯成文与有用提问研究.md。

## 实际测试范围

| 内容 | 实际情况 |
| --- | --- |
| 10篇写作 | 8场景加2次另一文风回放；短回答、晚说感受、否定纠正、平淡日、时序、编辑与追加 |
| 输入 | 预编虚构问答；不是用户真实日记，也不冒称10组提问都由API即时问出 |
| 成文 | 事实整理、全文写作、观察、磁盘归档为实际API/应用流程 |
| 基线 | 旧3.0.5，只给正文/回答；保留相同基线，非单变量受控实验 |
| 成功新版 | 同10篇在4.0.0、4.0.1、4.0.2迭代，主成功稿4.0.2，全部旧稿保留 |
| 提问对照 | 8个相同前文的真实响应，经实际应用reply路径；成功版本4.0.1，提问提示与当前一致 |
| 最终4.0.3写作候选 | 分离写作/陪聊角色，消化问答共同支持的省略，避免采访痕迹；平淡日复测4次HTTP429，未成功，不计完成 |
| HTTP记录 | 137条，132条2xx、1条网络超时、4条429；状态为HTTP统计，不当成内容质量通过率 |

当前配置服务返回的是上游排队与频率限制。遇429后停止新API任务，失败保留；没有换其他服务/凭据，没有把原稿改成看似成功的新稿。密钥沿用明确授权的内存读取/解密，仅用于虚构测试；日志不保存请求头，凭据字符串作脱敏，未读取真实日记。

## 效果复核

Agent读稿表见test-results/coherence/REVIEW.md，具体前后文本在writing/*.md，问题对照在questions/*.md。分数是Agent主观判断，没有盲评或统计意义，不是服务模型自评分，也不是真人验收。

指代、晚补感受、当前稿/新增片段的局部归属更清楚；时序案例保留昨天退货今天到账、计划上线未上线、抵租非现金。追加原文与删除保护保持。

流畅度改善有限。4.0.2平淡日仍写“有人问起”“不用总结道理”，把采访/写作要求带入文章；有主体过度确定、零碎段落、突然回跳中午的例子。最终4.0.3针对这些问题修订，但被429阻止，不能声称已验证改善。提问带过午饭、留下说话空间的样例较好；提案取消的重要样例仍被过早转走，部分追问仍可能价值不足。未将这些失败平均掉。

## 工程核对

- TypeScript、构建和独立CommonJS载入通过，运行时仅obsidian外部依赖。
- 89项集成/界面流程通过，含3个新增集成场景：问题进入两阶段写作及事实稿恢复；删文不经旧问题回流；事实阶段来源变化阻止后续写作。
- Chromium桌面、主题、手机360/390/412、短视口、输入焦点/组合保护、预览编辑归档，以及实际生成文本重放通过。浏览器是模拟宿主，不是实际Obsidian或Android。
- 产物检查：10份成功正文/事实文档/对应问题/实际响应/来源/归档一致；8个实际问题响应匹配；已删内容不回流、追加前缀保留。出处检查不证明每一句事实或心理解释正确。
- ZIP的CRC、六文件白名单、版本、源码与安装目录字节、SHA256和旧包保护，见coherent-package-check.json。

实际Obsidian、Android软键盘、官方Sync及本人完整试用仍待验。此次不是全量月级测试，0.3.0的62天资料保持历史身份。
