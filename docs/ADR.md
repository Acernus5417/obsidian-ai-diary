# 首版技术决策（2026-10-12）

> 0.2.1 对问答与主题的修订见 ADR-006；以下 ADR-002/004/005 中有关 JSON 对话、40 条截断与角度规则的描述是历史记录。

## ADR-001：宿主、构建与凭据

固定 Obsidian 类型包 1.11.4，最低运行版本 1.11.5；TypeScript 5.9、esbuild 浏览器 CJS 构建，运行时只 external Obsidian，不依赖 Node/Electron。已通过类型检查与浏览器构建。使用 SecretStorage 存值，普通设置仅保存随机仓库命名空间下的引用。设备 ID 使用宿主 vault-local storage。桌面凭据与 Android 持久化仍需实机验证。

类型包引入的旧 moment 开发依赖通过 override 升到 2.31+，锁文件固定；不将 moment 打进插件。设置跳转无公开 API，使用可选宿主设置入口，并提供文字回退路径，不影响记录功能。

## ADR-002：单文本网关

首版仅 Chat Completions 文本非流式。明确保留用户代理路径，支持根地址或完整 chat/completions 地址。90 秒超时，取消为应用层丢弃。模型输出 JSON 本地校验；JSON 解析失败最多一次格式修复，语义/schema 失败直接给可恢复错误。服务与模型未选择，假 HTTP 测试不宣称真实服务兼容。

## ADR-003：可同步事件段

普通目录内，按设备与写入实例独立追加完整性校验块。eventId 去重，父事件恢复因果，缺块/未来版本停止写入并保留原文。并发草稿保留分支，只有抑制之后有因果依据的用户重开才恢复。内容哈希用于意外损坏检测，非密码学验证。首版无旧生产 schema；不猜测迁移未知 schema，保留文件并请求兼容版本恢复。

模拟双设备时，只传输该写入端的新内容，不能把另一端未修改的旧文件当新修改覆盖。已以独立离线文件集验证并发草稿。正式 Sync 的 Markdown 合并、延迟和冲突副本仍需最终验证。

## ADR-004：编辑权威与归档

正文当前文件/当前预览优先，新增回答由消息 ID 消费集合判定。生成与写入分离，保存前 Vault.process 比较基线；正式文件变化拒绝覆盖。归档 prepared → 恢复副本 → 正式笔记 → 可读问答 → completed，事务标记避免重复追加。备份文件包含内容哈希，保留重试之间不同人工版本。

标记损坏时不猜测重整合结构，可追加或手动整理。已开始一个未归档补记预览后固定该次模式，下一次补记重新选择。用户需要换模式时先完成本次或手动处理，避免将追加片段误当全文覆盖。

已有记录后目录设置不自动移动；需要后续显式迁移操作。资料限 Markdown、白名单内读取，最多 300 文件元数据候选、6 个片段；历史观察不作为证据。长会话用最近 40 条对话与全部已问问题，原始记录全保留；超过写作请求预算时明确要求先归档，不静默截断正文素材。来源映射不能自动证明语义绝对真实，真实模型和完整版本预览仍需验收。

## ADR-005：0.2.0 体验线索与兼容

DayMap 从当天用户原文和经校验的消息注解重建，记录片段、感受、念头、期待、变化、已问角度和焦点。旧消息仅生成原文的情境标签，不推断情绪。每条注解保留消息 ID 与连续引文，否定不能被截成肯定；这是检索与回顾索引，不是新的正文事实来源。

reflection / moments 使用 assistant-message 的可选字段，片段焦点使用 topic-changed 的可选字段；事件版本继续为 v1。新版本严格检查这些字段，旧版本能忽略额外字段并保留原始事件块；不重写已存在的事件或正式日记。回退保留数据备份，旧版本不具备新的体验回顾能力。

单服务单模型完成线索、动作和自然表述；应用提供可考虑角度而不要求填满。对话格式与语义共用一次修复预算，最多两次请求；写作和观察仍各自最多一次 JSON 结构修复。请求失效或权限变化不触发额外修复。

写作仍仅接收当前正文和未消费用户回答，DayMap 和旧问答不作为额外素材回流。跳过的 sourceIds、关联注解和问题从后续模型上下文过滤，抑制状态仍跨日期与设备保留。

AI 消息增加 historyEvidence 路径/哈希，并继承输入中其他 AI 消息的历史依赖。撤回授权、文件改写或删除后，相关派生消息不再进入后续模型上下文；发送前与响应采用前都检查所依赖的版本。来源不明的旧 AI 消息留在本地问答中，不自动重新发送。该索引不作为正文事实，也不发送成冗余的内部路径列表。

## ADR-006：0.2.1 由模型把握自然回顾

用户明确要求简短框架、发挥模型能力。移除角度规划、情绪/动机词表、重复维度禁令、问句数量与强制分类校验。对话使用原生 user/assistant 消息，直接接收自然语言，兼容读取旧 JSON 回复。仅在没有可读内容时重试一次；不因语义风格触发修复。日记与观察的结构化来源协议继续保留。

默认从早上具体经历问起，以事件、感受/念头、后面一段时间为松散线索。示例帮助模型理解节奏，未引入按轮数强制切换时段的状态机。已选入口仅在明确选择动作中提示，避免自动归类持续引导后续问答。发送完整的已授权安全对话，不截断为最近 40 条；100000 字符的请求预算仍提示先归档，未实现无限上下文。

DayMap 仅保留原文导航和旧注解兼容，既不指挥问答，也不回流成文。来源版本、撤权过滤、明确跳过、编辑权威与归档事务继续生效。页面直接引用宿主 CSS 变量，不覆盖明暗主题色。

验证以已有集成/界面检查、Chromium 和当前 API 的虚构日程真实交互为主；未新增性能或单元测试。评分由 Agent 阅读输出后给出，不是自动质量通关，也不代表本人或 Android/Sync 已验收。

## ADR-007：0.3.0 原文历史与周期回顾

独立观察读取获准的历史日记正文，采用近期和间隔材料的字符预算，不采用情绪标签筛选。3.0.3全量测试曾给出前三天AI假说作非事实提醒；真实复核仍出现前提串联和重复观点，最终删除该输入，让每次理解回到原文。观察自由组织成一篇理解与引用ID，旧patterns仍兼容，不以两个日期或固定心理分类判定能否产生观察。

周记按周一至周日，月记按自然月，单独目录并注明N/周期天数。启动只补已经结束的周期；日记确认归档后才包含当天恰好为周期末的情况。未记录的日子不补写。事实输入限获准正文，观察、问答和AI周期笔记不回流为证据。

已有回顾不覆盖，写入前复核授权和来源，检测到本地新建竞争时留备选。日记归档先完成，周期失败可重试；关闭应用后阻止后续模型调用，已经开始的归档事务继续补齐。该竞争保护没有被表述为真实双端Sync冲突已解决。

全量62日真实测试与同原文定向修订分开保留。主观Agent意见、同服务辅助评分、出处结构检查与实际浏览器重放分别标明证据范围，不以自动分数或链接存在证明心理理解正确。格式/引用无效可修复一次，程序不自动重写情绪含义。

## ADR-008：0.4.0 问答语境、事实文档与成文

写作分为事实整理和全文撰写，接收当前正文、新回答和有效问题，事实文档包括已表达体验及可选篇章建议。写作可对照原问答修正事实稿，不能把模型整理稿变成更高权威。事实稿逐条sourceIds；正文返回全文sourceIds，sourceMapScope=document，避免让写作模型逐段重复正文来做协议映射。旧sourceMap输入仍可读。粗范围出处不证明每句话真实。

新问题记录正文哈希及所依赖回答ID，历史依赖继续记录路径/哈希；编辑、已消费回答、撤权及来源版本改变会使旧问题不再进入后续上下文。初次有效旧问答可读，已有编辑稿后来源不明的问题只留本地。当前稿和新增回答保持事实权威，原始对话不擦除。

不新增事实事件类型，factDocument和conversationBasis是schema v1既有草稿/消息的可选字段，旧版本可忽略。手动编辑正文时清除旧事实文档，下一次重新整理，不用派生稿恢复已删内容。生成增加一次API调用，不添加心理分类器、问题价值分数或语义批准门禁。

本轮按用户限制仅10篇，保留所有版本。成功写作4.0.2，最终4.0.3候选因上游429未完成验证；8个提问对照的提示文本与当前一致。结构与工程检查通过不冒称语言问题完全解决。
