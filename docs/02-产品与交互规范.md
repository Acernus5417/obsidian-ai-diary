# 产品与交互规范

基线：2026-10-12。功能编号用于任务和验收追溯。

## 用户与成功条件

用户知道当天发生了什么，却不愿组织措辞。主要场景是晚上集中回顾；产品要允许他零散地说，通过有分寸的追问留下具体经历和自己的感受。

首版给自己和少量朋友使用，主要环境为 Windows 和 Android。默认中文界面、中文生成；实际文字可以包含其他语言。用户自己承担所选 AI 服务的配置和费用，插件没有统一模型后台。

成功同时满足三点：提问不机械、不重复盘问；正文保留用户语言；回看能找回重要细节。聊天时长、回答数量和主题覆盖率不作为用户必须完成的任务。

## 首版功能

| 编号 | 需求 | 核心规则 |
| --- | --- | --- |
| P01 | 单服务模型设置 | 地址、密钥引用、模型名称、连接测试；同一模型用于全部任务 |
| P02 | 独立工作区标签页 | 重复打开时聚焦已有日记标签，不再创建同一天的重复会话 |

| P04 | 自适应问答 | 每轮可接话、提问或自然转题；一次最多一个主问题 |
| P05 | 对话主动权 | 可自由发送、点击继续问我、换话题、随时生成 |
| P06 | 持久化与接续 | 输入草稿、已发送消息、主题状态和生成草稿可恢复；支持 Sync 后换设备继续 |
| P07 | 正文与 AI 观察 | 第一人称忠实正文；观察独立、有不确定性与历史依据 |
| P08 | 风格设置 | 自然随笔、连贯叙事；改设置不自动改写已保存日记 |

| P11 | 当天补记 | 每次选择追加或重新整合，预览后保存，当前正文优先 |
| P12 | 受控历史记忆 | 白名单资料、主动关心后续、跳过事件停止追问并跨设备生效 |
| P13 | 安装与错误说明 | 插件包、中文引导、明确错误、重试和恢复路径 |

## 页面结构

所有记录业务都在同一个独立标签页中完成。设置使用 Obsidian 插件设置页。首次配置缺失时，标签页显示明确的配置入口；填写服务参数不等于连接成功。

### 开始页

- 显示记录日期和已开启的入口，不摆放连续打卡、评分、完成比例或固定时长目标。
- 点击入口开始对话。已有未完成对话时优先恢复，不自动创建和覆盖同名文件。
- 日期属于会话身份：进入会话时按设备本地日历日期确定；跨午夜后原会话仍属于原日。跨设备接续继承原日期，不以新设备时区重命名旧会话。
- 普通流程记录当天；历史日记至少能从对应日记命令进入补记。大规模补录日期管理不是首版主流程。

### 对话页

- 主区显示对话，底部为多行输入框和发送；“继续问我”与“生成日记”保持容易找到。
- 切换入口放在轻量的“换个方面”操作中，避免常驻任务清单压迫感。
- AI 只回应时，不在计时后自动发送下一问题。用户可以继续说或点击继续问我。
- 中文输入法组合过程中 Enter 不触发发送；多行内容正常保留。键盘快捷键需有可发现的说明。
- 点击跳过或明确表示不想再聊时，停止该事件主动追问；关掉入口不删除已有记录。
- 已发送内容先记录到本机，再请求模型。请求失败时保留用户内容，不要求重打一遍。
- 未发送文字始终保留为输入草稿，不算成已经讲述的事实。生成时存在未发送内容，应在同页提示可发送后再生成或仅生成已发送内容，不能悄悄丢弃。
- 没有任何记录素材时生成按钮不可用，并说明先提供一点素材即可；仅一条回答也能生成短日记。

### 预览页

- 同一标签整页展示可编辑正文、独立 AI 观察、保存位置及归档操作。
- “返回对话”恢复原来的进度、输入和已编辑草稿；仅切换页面不重新生成。
- 返回后新增回答，再次生成时以当前草稿和新增回答整合，保留已做编辑。
- “重新生成”保留当前稿的可恢复版本；不以重新读取全部问答来复活已删除内容。
- 生成、观察任一阶段失败，保留已有成功内容；观察失败不把正文清空，也不伪装成已经完成观察。
- 仅在用户确认归档后更新正式日记。预览自动保存位置与正式归档位置区分清楚。

### 归档与补记

- 正式日记：`日记/YYYY/MM/YYYY-MM-DD.md`，目录名称可配置。
- 可读原始问答：`原始问答/YYYY/MM/YYYY-MM-DD.md`；两篇笔记互相链接。
- 当天再次打开时展示已有日记和继续记录入口；补记阶段明确选择追加或重新整合。
- 追加只添加新的日记内容，保留当前正文原样；重新整合使用当前正文与新回答。
- 保存前发现正式笔记已被用户或同步改动，保留双方内容，在同标签显示版本对照与处理入口；不盲目覆盖。

## 设置项

| 分组 | 首版内容 |
| --- | --- |
| 模型 | Base URL、模型名称、凭据引用、测试连接；协议只显示实际支持项 |
| 写作 | 自然随笔 / 连贯叙事 |
| 入口 | 名称、启用状态、顺序；新增、删除或关闭 |
| 历史资料 | 允许的日记目录、指定 Markdown 文件与文件夹；移除授权立即影响后续请求 |
| 归档 | 日记目录、问答目录；校验路径冲突、非法路径与同名文件 |

入口排序、默认中文、初始折叠 AI 观察、目录名称是工程默认值，最终完整版本可根据试用调整。记录页不展示协议参数、检索分数和事件编号等实现信息。

## 异常体验

| 情况 | 必须发生的行为 |
| --- | --- |
| 缺少密钥或模型 | 给出具体配置入口，保留已有草稿 |
| 网络断开、限流 | 保留本机记录，显示可重试状态，避免重复发送消息 |
| 停止等待、超时 | 不再采用该响应；不能暗示服务端一定停止计费 |
| 模型返回无效格式 | 保留用户素材和前一有效稿，提供受控重试；原始 JSON 不渲染到对话 |
| 归档中断 | 恢复后识别未完成事务，补齐或恢复，不生成多篇正式日记 |
| 同步带来新版本 | 有未保存编辑时先保留本地稿；只在明确必要时要求处理版本冲突 |
| 插件卸载或升级 | 已归档 Markdown 可独立阅读；升级迁移前保存可恢复副本 |

## 首版边界

插件内录音、多服务路由、侧栏或弹窗记录形态、强制打卡、自动心理诊断、面向公众的账号体系和公开社区发布均不列入首版任务。用户后续主动提出的新需求按优先级另建版本，不偷偷加入当前范围。
