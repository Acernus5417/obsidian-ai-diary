# 0.2.1 测试与真实交互报告

2026-10-13。完整文件清单见 docs/12-测试文件与输出索引.md。本轮未新增或运行性能、单元测试；维护并执行已有集成/界面流程，重点检查真实 API 的虚构日程交互与主题效果。

## 本轮实现

- 对话使用简短框架、一个日常示例和原生 user/assistant 消息，直接接收自然中文。事件作为回忆入口，感受和念头为重点，按实际作息自然往后回顾。
- 移除角度候选、情绪/动机词过滤、同维度追问禁令、问句数量与强制分类门槛。片段索引仅供原文导航。旧 JSON 回复与旧注解可读。
- 入口只在用户主动选择时提示模型，避免自动标签持续带偏。完整已授权安全对话进入模型；没有最近 40 条截断，现有请求预算提示仍保留。
- 页面使用 Obsidian 的配色、字体、边框、按钮和阅读宽度变量；去掉固定配色、品牌装饰和横向大标题，收敛正常字号与平实文案。
- 日记按事件整理回答、衔接与去重；授权、明确跳过、独立 AI 观察、当前编辑优先、版本保护和归档恢复保留。

## 真实 API 测试

使用插件当前配置的 deepseek-v4.1-flash。用户明确授权本次读取并在内存中解密插件凭据。只发送虚构日程，不读取真实 Markdown 日记，不在输出、普通配置或 ZIP 中保存密钥。

三个剧本为工作日、平淡休息日和夜班。模拟用户根据实际问题回答，提问模型看不到隐藏剧本；实际网关、应用与归档代码运行在隔离内存仓库。

| 轮次 | 提示词 | 实际记录 |
| --- | --- | --- |
| initial | 2.1.0 | 工作日/夜班各 8 次回答；38 请求、38 响应，2 份归档 |
| revised | 2.1.1 | 三场景各 10 次回答；75 请求、75 响应，3 份归档 |
| final（候选名） | 2.1.2 | 两场景完整保存，检查点 39 请求/响应；夜班途中超时退出，未保存部分不计成功 |
| optimized | 2.1.3 | 34 请求、33 响应；保留生成 502、平淡日及夜班模拟回答超时，1 份部分素材归档 |
| recovered | 2.1.3 | 原对话接续，只补未完成部分与重试生成；32 请求/响应，三场景各 8 次回答，3 份归档，当前恢复轮无错误 |

另外，夜班在 8 次回答时尚未到晚上，再加两次回答单独记录为 night-extension，不倒算为 8 次已覆盖。完整问答、剧本、生成日记、观察、来源、恢复动作和失败历史均在 recall-*.md/json。脚本也保留 previousErrors，未把恢复前的失败抹掉。

night-extension 实际 6 次请求/响应，无错误，归档完成；10 次回答时覆盖 8/8 事件组，保留“还在上班”的时间边界，未补造之后回家或睡觉。遗漏的并存感受仍记录为不足。

## 还原效果评分

详见 test-results/recall-review.md。由 Agent 阅读真实文本评分，没有让服务模型给自己评分，没有用情绪词数量代替质量。

- 工作日在相同 8 次回答预算下，关键事件组由 3/8 提高到 8/8，全天覆盖评分 2/5 → 5/5；能留下“时间没被当回事”“总算有一件自己想做的”等内心原话。
- 最终平淡日覆盖 8/8，接受晚起、普通家务和没有深意，未把上月电影写成今日事实；仍有“自然醒”等未确认判断和多余评价，语气 3/5。
- 夜班在 8 次回答下覆盖 6/8，与第一轮相同，尚未充分问出想家与不回老家工作的并存感受。模型尊重不深聊洗衣机，未把请假未定写成已成行；需要追加回合覆盖晚上。

正文按实际用户回答核对，隐藏剧本用于看遗漏，不用于给模型补写。最终工作日正文未写入助手推测，整理为五段；夜班仍残留“不想细聊”的对话措辞，整理有提升空间。

这不是受控统计实验或本人试用。模拟用户和模型具有随机性，也可能过度配合。工作日有明显改进，不能据此声称每种情绪和作息都能更好还原。

## 当前边界与兼容

事件仍为 schema v1，旧日记、对话与接续记录不批量重写。写作仅使用当前正文/编辑稿与新增回答；导航索引、助手回复和历史观察不作为重新整合的额外事实。撤权与历史版本变化仍过滤派生上下文。

当前服务本轮出现过 502 和超时，插件保留已发送内容并支持重试。恢复成功不代表服务以后不会失败。部分自然对话仍有事实细问、评价、过早收尾或未确认理解；本轮没有用词表或情绪规则去封堵。

实际 Obsidian 宿主、Android 真机、软键盘、官方 Sync 和本人完整试用仍未验收。真实服务测试与浏览器重放不替代这些检查。
